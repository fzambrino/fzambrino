## Main Projects
- ### SAfeGuard  
SAfeGuard is a scalable mobile‑first platform for emergency management, combining a Flutter client, a Dart/Shelf backend, Firestore real‑time data persistence, and an AI microservice for geospatial risk analysis. It enables bidirectional communication between citizens and rescue teams, ensuring operational continuity even without internet connectivity.  
  
Link GitHub: [SAfeGuard](https://github.com/SAfeGuard2025/SAfeGuard)

- ### SAfeRoute-AI  
SAfeRoute AI is an evolutionary module of the SAfeGuard emergency‑management platform. It transforms static emergency data into dynamic, risk‑aware evacuation routes by combining real‑time Firestore data, geospatial modeling, and optimized pathfinding algorithms (Dijkstra and Bidirectional Dijkstra). Built with FastAPI, OSMnx, and NetworkX, it provides safe‑route computation and real‑time guidance during natural disasters.
  
Link GitHub: [SAfeGuard-AI](https://github.com/SAfeRoute-AI-Project/SAfeRoute-AI)

- ### Football Injury Prediction
This project applies supervised binary classification to predict the risk of muscle injuries in football players. Using historical, biometric, and workload data, the system identifies early warning patterns to support medical staff in making proactive decisions. The model prioritizes Recall to minimize false negatives and leverages Logistic Regression, advanced feature engineering, and interpretability analysis to uncover key injury‑risk drivers.
  
Link GitHub: [Football Injury Prediction](https://github.com/fzambrino/football-injury-prediction)

##  Currently Working On
I am developing a real‑time tactical analysis system for football matches, based on player tracking data extracted through computer vision. The goal is to automatically identify team formations and role assignments during a match, overcoming challenges such as dynamic player movements, role swaps, occlusions, and the need for online (real‑time) processing. The solution integrates modern detection and tracking pipelines, spatiotemporal modeling, and state‑of‑the‑art methods from the literature to infer tactical structures from raw positional data.
